A small model of a big idea.

The pipeline is interactive and deterministic: the same inputs produce the same outputs. There are no external libraries, model downloads, network calls or API keys.

What really runs

Text cleaning, overlapping word chunks, sparse TF-IDF vectors, cosine similarity, source filtering, reranking, context packing and source-linked sentence selection.

What is simplified

Vectors count words with a few explicit synonyms. They are not learned semantic embeddings. The in-memory array is a tiny index. The answer uses source sentences; it is not an LLM response.

What real RAG adds

Production systems may parse PDFs, enforce document permissions, use learned dense embeddings and a search service, then call an LLM. Optional reranking and evaluation vary by application.

What to be careful about

Matching words cannot establish truth or fully interpret meaning, negation or intent. A citation does not prove that an answer is complete. Real RAG also needs reliable sources and evaluation.

Read the matching rules

English text is lowercased, common words are removed, a small synonym dictionary is applied, then terms receive TF-IDF weights. A query uses exactly the same vocabulary and weights as the chunks. Cosine similarity ranks matches. Optional reranking combines 65% cosine score with 35% query-term coverage. The simulated answer abstains if the packed context covers less than 45% of query terms. This is a teaching heuristic, not a reliability guarantee.

Offline preparation is repeated when documents or chunking change. At question time, the document index is reused; only the question and downstream results change. This file keeps its index in memory.
